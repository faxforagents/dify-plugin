# Privacy

This plugin sends your API key and the tool inputs to the Fax for Agents API
(api.faxforagents.com) and returns the results to Dify. The inputs are the fax
text or Markdown, destination numbers, cover sheet fields and the document, quote, fax and inbox
ids. It stores nothing itself and sends nothing anywhere else.

Fax for Agents processes this data under its privacy policy: https://faxforagents.com/privacy/

The text of a received fax and its sender header come back as data from whoever sent the fax.
